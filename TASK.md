# Same Ta (Бровари) — MVP проєкт «під ключ»

## Мета
Зібрати демонстраційний MVP-проєкт для кав'ярні **Same Ta** (м. Бровари, вул. Василя Симоненка, 105):
1. Мобільний односторінковий сайт-меню за QR-кодом (`site/` — HTML/CSS/JS, український інтерфейс, без бекенду, готовий до GitHub Pages / Vercel).
2. Telegram-бот для передзамовлень (`bot/` — Python + `aiogram 3`, замовлення в 3 кліки, пересилка в чат бариста з кнопками статусу).
